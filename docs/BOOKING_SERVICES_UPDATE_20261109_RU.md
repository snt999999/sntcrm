# СОЛНЦАНЕТ — обновление услуг клиентской онлайн-записи (09.11.2026)

Источник: прикреплённый файл «Лист Microsoft Excel.xlsx» и последнее указание: убрать четыре прежние автоуслуги, сделать замер бесплатным.

## Как применить к существующему сайту

1. Сначала сохраните резервную копию Supabase (текущих данных) и предыдущую версию ZIP.
2. В Supabase Dashboard → текущий проект → SQL Editor → New query откройте `supabase/booking_services_excel_20261109.sql`, вставьте весь текст, нажмите Run. **НЕ запускайте booking_v1_migration.sql второй раз.**
3. Скрипт обновляет ТОЛЬКО публичную таблицу `booking_services`; ничего не удаляет. Существующие CRM-заявки и внутренний справочник услуг остаются без изменений.
4. Опубликуйте обновлённый сайт в Cloudflare Pages тем же способом, что использовали для рабочей сборки. Для серверных функций — Wrangler/Git-деплой (простая загрузка статического ZIP не развёртывает `functions/`).
5. Обновите страницу онлайн-записи через Ctrl+F5 и проверьте услуги и тарифы.

## Публичный каталог

- Архитектура: 6 наименований, «Замер» и «Монтаж» (кроме «Замер / консультация», где только «Замер»). Итого 11 вариантов.
- Любой «Замер» — бесплатно, цена 0 ₽, длительность 60 минут.
- Архитектурный «Монтаж» — цена от 1600 ₽/м², расчётный слот 60 минут (длительность «от 1 часа» из Excel; фактическое время согласовать с клиентом).
- Авто: 16 наименований из Excel; 14 имеют цену и время, опубликованы.
- «Демонтаж пленки» и «Демонтаж клея» оставлены в каталоге CRM онлайн-записи, но НЕ опубликованы: в Excel отсутствуют цена и продолжительность. Включить их можно после ручного задания длительности.
- Исключены из клиентской онлайн-записи: «Форточки», «Бронирование 1 фары», «Бронирование противотуманных фар (1 шт)», «Доплата».
- Внутренний список услуг CRM не менялся, старые записи не удалялись.
